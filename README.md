# The Twelfth Chapter

A static Halloween birthday treasure hunt, built for one shared iPad.

Open `index.html` through an HTTP(S) server. Paper clue cards are required for the physical quest.
Add `?rehearsal=1` to rehearse every puzzle on screen with separate saved progress.
Progress is saved on the current browser only. For the Keeper contains hint/rescue/reset controls.
Show last clue repeats an unlocked hiding clue without changing progress. Keeper controls require the parent's PIN and re-lock on close.
The PIN is a casual spoiler guard for this static game, not secure authentication.
Original synthesized castle-door and incorrect-answer lock effects are included, with previews and an independent Effects on/off control.
Original SVG cobwebs, a slowly descending spider and candle-flicker pumpkins frame the story. Decorative movement respects reduced motion and stays behind the controls.
Music uses one visible YouTube player, with a 12-second Unstoppable chorus cue from 0:46 for correct answers under one minute or every third consecutive correct answer, and Natasha Bedingfield's Unwritten finale from 2:01.
Opening the final chapter attempts the celebration video; tap Play if the browser blocks autoplay. Internet required; YouTube may show ads.
No music-file import is needed. Player controls remain visible, and closing the player stops it.
The cover uses the parent's supplied stylized Halloween group illustration. Room/bookshelf and invitation photos stay private.
No commercial recordings, private address, analytics, accounts or server database are included.
