# The Twelfth Chapter

A static Halloween birthday treasure hunt, built for one shared iPad.

Open `index.html` through an HTTP(S) server. Paper clue cards are required for the physical quest.
Add `?rehearsal=1` to rehearse every puzzle on screen with separate saved progress.
Progress is saved on the current browser only. For the Keeper contains hint/rescue/reset controls.
Music plays from purchased audio files selected locally on the iPad, with a first-answer victory cue and automatic finale.
Files stay in the current tab only; after reload, reselect files and tap Start music. Official listening links are optional.
No commercial recordings, invitation photos, private address, analytics, accounts or server database are included.
